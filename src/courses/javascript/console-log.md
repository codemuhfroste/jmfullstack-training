# Hello, console

HTML is the structure and CSS is the look. **JavaScript** is the behaviour: the language that makes a page *do* things.

Before touching a page, start with the simplest possible program. `console.log()` prints a message to the **console**, a text output that developers use to see what their code is doing:

```js
console.log("Good morning!");
console.log(2 + 3);
```

- Text is called a **string**, and it goes in quotes. Single (`'…'`) and double (`"…"`) quotes both work.
- Numbers are written without quotes.
- A line that starts with `//` is a **comment**. JavaScript ignores it.

Each statement ends with a semicolon. Press **Run** to execute your code and see the console below the editor.

## Task

Print exactly this line to the console:

```
Welcome to Brewline!
```

## Hints

- The message is a string, so it needs quotes around it.
- `console.log("Welcome to Brewline!");` Watch the capital letters and the exclamation mark, because the check compares the text exactly.

## Starter

```js
// Print the welcome message below

```

## Solution

```js
// Print the welcome message below
console.log("Welcome to Brewline!");
```
