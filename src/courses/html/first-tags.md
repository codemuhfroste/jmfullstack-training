# Your first tags

Every web page starts as plain text. **HTML** adds meaning to that text by wrapping it in **tags**.

A tag has an opening part, some content, and a closing part with a slash:

```html
<h1>Good morning</h1>
<p>This is a paragraph of text.</p>
```

- `<h1>` is the main heading of a page. There are six levels, down to `<h6>`.
- `<p>` is a paragraph.

Together, an opening tag, its content and its closing tag are called an **element**.

> Throughout this course you'll build the website for **Brewline**, a tiny coffee cart. The preview on the right updates as you type.

## Task

Brewline needs a front page. In `index.html`:

1. Add an `<h1>` heading with the text **Brewline**.
2. Under it, add a `<p>` paragraph that describes the cart in a short sentence.

## Hints

- Type the opening tag, the text, then the closing tag: `<h1>Brewline</h1>`.
- The paragraph works the same way with `<p>` and `</p>`. Write at least a few words between them.
